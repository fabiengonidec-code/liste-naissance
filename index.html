Comment restaurer ?

        

          1. Copiez ou téléchargez le JSON ci-dessus.

          2. Dans la console Firebase → Realtime Database → onglet Données.

          3. Cliquez sur les 3 points ⋮ à côté de la racine → Importer JSON.

          4. Collez votre fichier — toutes les données seront restaurées instantanément.
